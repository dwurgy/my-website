I’m David Wurgler. I design and build software, and I live in Salem, Oregon, with my wife and our two boys.

I make my apps with Claude, an AI from Anthropic, as my coding partner. I decide what each one is and how it should feel: the design, the details, the way it behaves. Claude and I write the code together and catch each other’s mistakes.

I build the things I wish already existed: quiet, well-made tools that respect your time and your privacy.

make

I don’t write most of the code. I write the brief.

Every project starts with a document: who it’s for, the rules the agent can’t break, and a done test for each step. Then I direct Claude Code through it in pieces small enough to check.

  • Work in small, testable steps.
  • No new dependencies without asking.
  • Never weaken a security default.
  • Each phase ends with a done test.

I care about how it feels, not just how it looks. Good software should be pretty to look at and easy to use. Then it should get out of your way.
